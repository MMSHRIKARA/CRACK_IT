HIBERNATE
------------
Hibernate is an ORM(Object-Relational Mapping) framework for java that maps java objects to relational database tables & handles database operations automatically.

Advantages:
* Reduce boilerplate JDBC code.
* Database independent(uses HQL)

*  Hibernate configuration file : (hibernate.config.xml or hibernate.properties)
   -----------------------------
-> This file contains database related configuration & session related configuration.

* JDBC - Java Database Connectivity
   Advantages of Hibernate over JDBC
   ----------------------------------
	JDBC			Hibernate
	----			---------
Manual SQL			Automatic SQL generation
More code			Less code
No caching			Supports caching
DB dependent			DB independent

* LazyLoading : Data is loaded only when required, not upfront.
   Mainly used to improve application performance. Loads child objects only when parent object gets loaded.

* EagerLoading : Data is loaded upfront. Loads child objects along with parent object.

*  Important interfaces in Hibernate
   ----------------------------------

* SessionFactory : is a heavy object, created once per application, Used to create session objects.
* Session : is an object that maintains connection b/w java objects & database.
* Transaction : represents a unit of work, handles commit and rollback.
* Query : Used for creating & executing HQL or SQL queries.

*  Diff b/w get() & load()
   ------------------------
	* get() hits db immediately & returns null if not found.
	* load() lazy loading & throws exception if not found.
